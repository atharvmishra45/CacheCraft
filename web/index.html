Algorithm Architecture & Hackathon Pitch

O(1) Proof
What is LFU (Least Frequently Used)?
LFU tracks the total number of times each campus document is accessed. Items that are accessed rarely are prioritized for eviction when fast memory fills up.
What is LRU (Least Recently Used) & Why pair it with LFU?
Pure LFU suffers from ties when several documents have the exact same access count (e.g., both accessed once). CampusCache uses LRU recency as a tie-breaker: among documents tied at the lowest frequency, the one accessed least recently is evicted.
How does CampusCache achieve strict O(1) for GET & PUT?
  • HashMap<Key, CacheNode>: Locates any cached node in O(1) without linear scans.
  • HashMap<Frequency, DoublyLinkedList>: Groups nodes having the same access count. Removing and prepending to doubly linked list takes O(1).
  • minFrequency integer: Tracks the global lowest frequency. When an item is promoted or inserted, minFrequency is updated in O(1).
